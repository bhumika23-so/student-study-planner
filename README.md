📚 Student Study Planner

A simple and beginner-friendly web application designed to help students organize and manage their study tasks.

🌐 Live Demo

"Open Student Study Planner" (https://bhumika23-so.github.io/student-study-planner/)

✨ Features

- ➕ Add new study tasks
- 🎯 Set task priority:
  - High
  - Medium
  - Low
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📊 View the number of pending and completed tasks
- 📱 Simple and user-friendly interface

🛠️ Technologies Used

- HTML – Structure of the application
- CSS – Styling and layout
- JavaScript – Functionality and task management

📂 Project Structure

student-study-planner/
│
├── index.html
├── style.css
└── script.js

🚀 How to Use

1. Enter your study task in the input box.
2. Select the priority level.
3. Click Add Task.
4. Your task will appear in the task list.
5. Click Complete when you finish a task.
6. Click Delete to remove a task.

🎯 Purpose

This project was created as a practice project to learn and apply the basics of HTML, CSS, JavaScript, GitHub, and web deployment using vibe coding.
